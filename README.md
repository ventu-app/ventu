# 🦊 Ventu — Play. Speak. Survive.

O **Ventu** é um RPG de sobrevivência em inglês. O jogador não estuda: ele vive situações reais, digita (ou fala) para resolver problemas, e cada resposta muda a história.

## 🚀 O Projeto
Webapp construído com foco em performance, acessibilidade e design premium, utilizando tecnologias web nativas (Vanilla).

- **Site no ar:** [ventu-app-ingles.vercel.app](https://ventu-app-ingles.vercel.app)
- **Stack:** HTML5, CSS3, JavaScript (Vanilla). Hospedado na Vercel.

## 🎮 Os Níveis (CEFR + Real World)
O jogo escala a dificuldade e o tipo de "pepino" que o jogador precisa resolver:
- **A1 a B1:** Sobrevivência básica, resolução de problemas do dia a dia, burocracia.
- **B2 a C2:** Negociação, ironia, política, debates e persuasão.
- **Módulos Especiais:** Flerte (Social) e Conflito/Palavrões (Street).
- **Vida no Exterior:** Foco em intercâmbio, Au Pair e trabalho fora.
